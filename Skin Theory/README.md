# Skin Theory

## Web Development Project

Skin Theory is a skincare website created as part of the Web Development module. The website provides users with information about skincare products, gift sets, the Skin Theory brand, and ways to contact the business.

The website was developed using HTML and CSS, with a focus on clean presentation, consistent styling, accessibility, usability, and responsive design across desktop, tablet, and mobile screen sizes.

---

## Project Purpose

The purpose of the Skin Theory website is to provide customers with an easy-to-use online skincare experience where they can:

- Learn about the Skin Theory brand.
- Browse available skincare products.
- Explore skincare gift sets.
- Read information about different products.
- Find contact and location information.
- Submit an enquiry through the enquiry form.
- Navigate between the different pages of the website.

The website uses a simple and clean skincare-inspired visual design to create a consistent user experience throughout all pages.

---

## Technologies Used

The following technologies were used to create the website:

- **HTML5** – Used to structure the web pages and their content.
- **CSS3** – Used for styling, layout, colours, typography, spacing, responsive design, and interactive visual effects.
- **Git** – Used for version control and tracking project development.
- **GitHub** – Used to store and manage the project repository.

No JavaScript is required for the website's styling or layout.

---

## Website Pages

The website consists of the following pages:

### 1. Home Page

**File:** `index.html`

The home page introduces Skin Theory and provides an overview of the website. It includes navigation, promotional content, featured information, products, and links to other sections of the website.

---

### 2. About Page

**File:** `about.html`

The About page provides information about Skin Theory and the brand. It introduces visitors to the purpose and identity of the skincare business.

---

### 3. Products Page

**File:** `products.html`

The Products page displays the skincare products available from Skin Theory. Products are organised into sections to make the information easier for visitors to browse.

---

### 4. Gift Sets Page

**File:** `giftsets.html`

The Gift Sets page provides information about skincare gift sets and presents available from Skin Theory.

---

### 5. Contact Page

**File:** `contact.html`

The Contact page provides customers with contact and location information. It allows visitors to find information about how to get in touch with Skin Theory.

---

### 6. Enquiry Page

**File:** `enquiry.html`

The Enquiry page contains a form that allows visitors to submit an enquiry.

The form includes fields for customer information and their enquiry.

---

### 7. Thank You Page

**File:** `thankyou.html`

The Thank You page provides confirmation to users after completing an enquiry.
