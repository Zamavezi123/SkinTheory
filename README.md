

## Part 2 — Build, Feedback Corrections, and Enhancements

Following Part 1 feedback, the site moved from planning into a full HTML/CSS build. Key
corrections and enhancements made in Part 2:

- Added a logo to the site header, which was missing in Part 1
- Removed the original shopping cart pages and rebuilt the purchase flow as a simpler
"Enquire about this product" system, ending in a dedicated Thank You page
- Added the Gift Sets page as an extra page beyond the five-page minimum
- Built out the full external stylesheet (`css/style.css`), including base/reset styles,
a consistent typography scale, colour palette, and layout using Flexbox and Grid
- Added responsive design with dedicated tablet and mobile breakpoints (and a small-phone
breakpoint) so the layout, navigation, and product cards adapt across screen sizes
- Added interactive styling (`:hover`, `:focus`, `:active`) across buttons, links, and
navigation for a more usable, polished feel
- General visual overhaul — the Part 1 version was very bare-bones; Part 2 improves the
overall look, spacing, and usability across every page
